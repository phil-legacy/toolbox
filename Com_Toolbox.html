Com Toolbox v0.1

A Modbus TCP server (slave) that lives on your PC. Your PLC reads and writes it as if it were a real device, and you see everything: the values, every frame byte by byte, and their evolution in time.

Start

  1. Run com_toolbox.py (double-click, or python com_toolbox.py). This page opens. Keep the black window open.
  2. In your PLC software (CODESYS…), add a Modbus TCP client (master) pointing to the IP address shown at the top of this page, port 502 (or the port shown).
  3. First start on Windows: allow Python through the firewall, or the PLC cannot connect.

Tabs

  • Tags: name the addresses, choose the type and the word order, and make values live (ramp, sine, counter, tank level, copy with delay, threshold).
  • Memory: the four Modbus tables, cell by cell.
  • Monitor: every request and answer, decoded byte by byte.
  • Trace: the tags over time, with cursors.
  • Lab: word order, address references, and a test client.
  • ⚡ Faults: delays, lost answers, exceptions, disconnections.

Simulator for training. Always validate your program on the real installation.
